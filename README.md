# ТКПСТ · админ-панель (закрыто)

Админка группы **ИС-25-3С**: вкладки «Изменение расписания» и «Посещаемость». Вход по паролю
(администратор, староста, куратор). Хостинг — Netlify, проект `tkpst-poseshchaemost`.

- `public/` — страницы админки (без сборки). `public/js/core.js` и `public/style.css` — копии из
  `tkpst-schedule/web` (логика расписания и стиль сайта); при изменении там — скопировать сюда.
- `netlify/functions/att/` — сервер: вход по паролям, посещаемость (Netlify Blobs), изменения расписания —
  сервер сам правит `web/overrides.json` в публичном репозитории `tkpst-schedule` ключом GitHub, который
  хранится в Blobs (подключается один раз со страницы «Изменение расписания»).
- `test/` — тесты; сборка на Netlify не пройдёт, если они упали.

Переменные окружения Netlify: `ATT_PASSWORD_ADMIN`, `ATT_PASSWORD_KURATOR`, `ATT_PASSWORD_STAROSTA`, `ATT_SECRET`.
После их изменения — Deploys → Trigger deploy.

Защита: вход 30 дней; после 8 неверных паролей с одного адреса — пауза 15 минут; CSP и запрет встраивания;
API доступно только с этого же адреса.
